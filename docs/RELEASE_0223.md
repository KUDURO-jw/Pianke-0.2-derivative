# 片刻·焕新版 0.2.23

## 性能

- 片库网格改用固定行高，滚动时省掉逐项测量。实测 1000 项连续滚动
  30 帧，458ms 降到 331ms（约快 28%）。
- 片库滚动时不再每帧复制一份完整的已展示 ID 集合，片库越大收益越明显。
- 数据库开启 WAL 模式：后台同步写入时，界面查询不再被写锁挡住。
- 移除未被使用的 flutter_animate 依赖，连带去掉 flutter_shaded，
  安装包更小、构建更快。

## 稳定性

- 片单批量导入在批次之间加入间隔，降低触发豆瓣风控导致整单失败的概率。
  代价是 100 部片单从约 30 秒变成 60~80 秒。
- 新增全局错误边界：构建异常与未捕获的异步异常会被记录下来，
  不再只表现为「点了一下没反应」。
- 设置页新增「导出诊断日志」，可把最近的错误记录导出成文本分享。
  日志只留在本机，不会上传任何服务器。

## 说明

- 本版没有改变界面外观与交互，是一次纯底层优化。
- 验证：静态分析零问题；前端测试 130 项、业务测试 183 项、
  视觉基线 6 项全部通过；动效令牌检查通过。

本版递增为 0.2.23（29），沿用 `app.pianke.personal` 与既有发布证书，
可从 0.2.22（28）直接覆盖更新，无需卸载。

### 验证边界

本版通过静态分析、组件测试与 Release 构建校验；未接入真机，
实际帧率与澎湃 OS 4 的表现需安装后验收。滚动性能数字来自
Flutter 测试框架内的组件渲染计时，不是真机帧率采样。

# 片刻·焕新版 0.2.22

## 弹簧动效

- 新增统一的弹簧按压组件：按下缩小、松开带过冲回弹，全应用同一套参数。
- 影片卡片、抽片历史、观影统计卡的按压反馈从补间曲线改为弹簧物理。
- 抽片结果登场、详情页评分星同样改为弹簧，回弹手感一致。
- 建立规则：位移与缩放走弹簧（能接收初速度），透明度与颜色走曲线。

## 视觉对齐

- 强调色统一走主题令牌，暗色模式下不再是偏暗的固定蓝，对比度达标。
- 圆角统一到设计令牌：胶囊、卡片、小元素各归其位，不再散落字面量。
- 字号阶梯全面令牌化，标题、正文、辅助信息的层级差异更稳定。
- 全应用硬编码颜色曲线清零，调整手感只需改一处令牌文件。

## 稳定性

- 修复按压反馈会重建整张卡片（含海报子树）的问题，长列表滚动更省。
- 修复「详情页页签」缺少稳定标识、无法被测试覆盖的问题。
- 修复防抖合并测试在并发环境下偶发失败。
- 修复 4 项长期失败的前端测试：它们断言的是已被移除或从未存在的实现细节。

本版递增为 0.2.22（28），沿用 `app.pianke.personal` 与既有发布证书，
可从 0.2.21（27）直接覆盖更新，无需卸载。

### 验证边界

本版通过静态分析、组件测试与 Release 构建校验；未接入真机，
帧率、触觉手感与澎湃 OS 4 的实际表现需安装后验收。

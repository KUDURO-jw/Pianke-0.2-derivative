- 详情未保存返回确认、固定保存入口、失败保留当前编辑。
- 抽片显示本地筛选后的候选数，支持逐项取消，空结果解释。
- 观影主页与日历可补记，选片本地搜索与分页，日期可改。
- 年度回顾在观影页更多菜单；按本地观影记录统计，可分享 PNG。次数与去重电影/剧集分别计数，评分使用当次评分。无当次评分不推算；无记录不凭已看状态补造。没有额外豆瓣请求。

## 可重复检查

```powershell
flutter analyze --no-pub
flutter test --no-pub
flutter build apk --release --target-platform android-arm64 --no-pub
./tool/verify-release.ps1 -ApkPath ./build/app/outputs/flutter-apk/app-release.apk
```

发布工具会核对 pubspec 版本、包名、ABI、apksigner 验证结果、既有证书 SHA-256，生成 APK SHA-256 与 release-report.json。当前证书与已安装焕新版连续，不能擅自换签。私钥和 key.properties 不进入源码或归档。

如明确发布，先上传 APK，再对公开下载字节核验：

```powershell
./tool/verify-release.ps1 -ApkPath <apk> -ManifestPath <待发布的清单.json> -PublicApkUrl <https公开APK地址>
```

只有公开下载字节与本地 APK 一致后才更新 update-ui.json；update.json 保留旧渠道。更新依然可跳过，安装仍需 Android 用户确认。本轮不因本地构建自动修改线上清单。

## 小米手机验收

1. 详情改短评后返回，依次验证继续编辑、放弃、保存并离开；断言保存失败时仍能编辑。底部保存与系统手势、键盘不冲突。
2. 抽片加时长、类型、标签筛选，比较候选数；无结果时逐项取消，确认数量与实际抽片一致。
3. 在观影页补记，在空白日历日期补记，修改日期与评分后保存；电影、剧集均回归原已看判定。
4. 年度回顾切年，重复观看算多次但作品去重。分享图片核对文字、图表，确认无短评、同伴、账号泄露；断网也可查看与生成。
5. 取消本地恢复预览应无写入。分别导入旧备份、重复记录、错误格式；观察实际统计，确认已有短评未覆盖。
6. 同步失败后查看错误，再连接重试；云端与本地均修改时查看预览。确认窗口打开期间改变数据，应拒绝用旧预览覆盖。
7. 真机另核验旧 SQLite 文件升级、杀进程重启、云端覆盖后恢复安全备份，以及原版分集完成判定。本轮未调整 SQLite schema；电脑的替代存储测试不等同于真机数据库迁移测试。
8. 浅/深色、320px 小屏、2 倍字体、键盘弹出、系统返回与快速连续操作分别查看。电脑测试不代表澎湃 OS 4 真机已验证，也不宣称固定帧率。

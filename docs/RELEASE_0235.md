# 片刻·焕新版 0.2.35

## 紧急修复：片库整页空白

**现象**：0.2.34 装上后，片库只剩标题和筛选栏，一部影片都看不到。

**根因**（我上一版引入的严重回归）：

我把网格从 `SliverGrid.builder` 换成 `SliverAnimatedGrid`，
为了实现补位动画。但 `SliverAnimatedGrid` 的 `initialItemCount`
**只在首次构建时生效**，之后不再跟随数据变化。

而片库数据是**异步加载**的：

- 首帧 `itemCount = 0`（数据还没回来）
- 数据到位后网格重新构建，但 `initialItemCount` 仍是 0
- 网格永远空着

实测对比（同异步数据场景）：

| 网格 | 数据到位后的卡片数 |
|---|---|
| `SliverAnimatedGrid` | **0**（空白页） |
| `SliverGrid.builder` | 3（正常） |

## 补位动画换了实现

`SliverAnimatedGrid` 这条路走不通（既有上面的陷阱，`removeItem` 也需要
在数据变化前精确调用，时序很脆弱）。改为：

**在删除前后各测一次卡片位置，把「旧位置 − 新位置」作为起始偏移
注入卡片，再动画回 0。**

- 由 `ReflowController` 统一管理，页面持有一个实例
- `captureBefore` 在删除前记录每张卡片的位置（用 `GlobalKey` 测量）
- `animateAfter` 在帧后比对，给发生纵向位移的卡片注入偏移
- 只处理纵向：横向变化（换列）属于整体重排，硬切更自然
- 遵守「移除动画」开关

这条路不依赖 widget 生命周期——中间还试过在卡片里用
`didUpdateWidget` 比较行号，但实测发现 `GridView.builder` 在
`itemCount` 变化时是**销毁重建 Element**，`didUpdateWidget` 根本不触发。

## 新增测试

`test/ui/library_reflow_test.dart` 5 项，最重要的一条在最前：

1. **异步数据到位后网格必须显示卡片** —— 直接守住这次的回归
2. 捕获前后位置，给移位条目注入偏移，动画结束归零
3. 关闭动画时不注入偏移
4. 新出现的条目不做补位动画（没有旧位置）
5. 补位时长使用 `Motion.normal`

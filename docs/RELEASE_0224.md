# 片刻·焕新版 0.2.24

## 修复：豆瓣抓取一直 403

这是本次最重要的修复。

**问题**：添加影片时豆瓣抓取持续返回 403，怎么重试都没用。

**根因**：豆瓣的挑战凭证 `dbsawcv1` 只有 **120 秒**有效期
（响应头 `Max-Age=120`）。原实现完全不解析 cookie 的过期时间，
把凭证永久存进本地偏好并反复发送。过期之后，每次请求都带着一份
失效凭证，豆瓣直接拒绝——所以越重试越不可能成功。

**修复**：

- 解析 `Set-Cookie` 的 `Max-Age` / `Expires`，过期 cookie 不再发送，
  也不再写入本地存储。
- 遇到 403 时先清空本地 cookie 再重试一次。挑战流程本身不需要任何
  既有 cookie，重来一遍就能拿到新凭证。
- 修正 `Expires` 的时区处理：`DateTime.parse` 不把 `GMT` 后缀当作
  UTC 标记，在 UTC+8 上会多算 8 小时，导致过期 cookie 被误判为有效。

**验证**：完整跑通「请求 → 拿到挑战页 → 解 PoW → 302 拿到凭证 →
带凭证请求 → 得到真实页面（122KB，标题正确）」全流程。

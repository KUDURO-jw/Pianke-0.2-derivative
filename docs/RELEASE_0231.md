# 片刻·焕新版 0.2.31

## 修复：撤销提示条下滑关闭时「最后还闪一下」

这是上一版没解决的问题。根因有两层，用逐帧采样才定位到。

### 第一层：退场只做透明度、位移几乎不动

实测数据（拖了 120dp 后松手）：

```
松手瞬间   opacity 0.250   ty 120.0
+16ms     opacity 0.237   ty 120.6
+208ms    opacity 0.009   ty 131.6
```

位移只从 120 走到 131.6，**多走了 11.6dp 就不动了**，而透明度一路降到 0。

观感就是提示条「停在半空慢慢变透明，然后突然没了」。

修复：退场时额外朝下再走 60dp，与手势方向一致，
读起来是「被甩出屏幕」而不是「原位淡出」。

### 第二层：entry 被移除得太晚

修完位移后仍有残留：透明度在 110ms 就低于 0.04（肉眼不可见），
但 overlay entry 还要挂到 416ms 才被移除。

多挂的那 300ms 里，提示条虽然几乎全透明，仍占着一个合成层。
移除瞬间下层要重绘，观感上就是最后闪一下。

修复：放大弹簧收敛容差到 0.05（「不到 5% 可见」即视为收束），
并把退场弹簧调硬（stiffness 350 → 1800），总时长从 416ms 压到 240ms。

### 期间踩的一个坑

第一版修法是用第二个 `AnimationController` 单独收束拖动位移，
与透明度弹簧并行跑。结果两条曲线互相拉扯：

```
ty: 120 → 117.8 → 120.8 → 124.8 → 129.4 → 129.2 → 127.5 → 124.4 → 120.3
```

**先往下再弹回**，折返比原问题更明显。

改为单一时间源：退场瞬间冻结拖动位移（`_exitDragStart`），
位移 = 冻结值 + 按 `(1 - t)` 叠加的甩出距离，全程单调。

它同时锁住了上面两个问题和那个坑。

# 片刻·焕新版 0.2.21

## 抽片动画

- 修复抽片定格时的弹性反馈完全失效：开奖放大与回弹此前一次都没播放过。
- 转盘从 2.6 秒压到 1.6 秒，曲线改为前段可辨方向、末端强减速，不再每帧闪一张。
- 洗牌时每张卡带轻微纵向位移，换卡看起来是从一个方向流过去，而不是原地替换。
- 抽片结果停留从 500ms 调整为 400ms，整体纯等待从 3.1 秒降到 2.0 秒。

## 动效规范

- 新增一套物理语言：位移与缩放走弹簧，透明度与颜色走曲线。全应用统一从这里取值。
- 底栏、抽片开奖、评分星统一到同一组弹簧参数，手感不再割裂。

## 稳定性

- 修复「跳过，再抽一次」每轮泄漏一个动画控制器的问题。
- 修复「移除动画」开启时抽片可能停在上一张卡的问题。
- 修复第二次抽片时开奖弹性不再播放的问题。
- 「今天」呼吸圆点现在是全仓唯一常驻循环动画，已改为遵守「移除动画」开关。

本版递增为 0.2.21（27），沿用 `app.pianke.personal` 与既有发布证书，
可从 0.2.20（26）直接覆盖更新，无需卸载。

### 验证边界

本版通过静态分析、组件测试与 Release 构建校验；未接入真机，
帧率、触觉手感与澎湃 OS 4 的实际表现需安装后验收。

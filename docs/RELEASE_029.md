# 片刻·焕新版 0.2.9

- 影片筛选刷新期间让过期请求自动失效，避免旧分页覆盖新搜索或筛选结果。观影记录与抽片历史采用相同保护，清空历史会取消仍在路上的旧分页。
- 自动同步、编辑页面退出及海报搜索结果都有异步销毁保护；限制影片详情缓存并淘汰过期日历月份。
- 影片及其观影记录、标签、合集引用在单个数据库事务中删除。删除合集和标签也在单个事务完成。
- 豆瓣搜索支持明确提交和搜索输入提交，分页失败时保留结果并重试。片库支持搜索片名、导演和演员；空结果能直接查看全部影片。搜索添加区域扩大至无障碍最小触控尺寸。
- 片单导入逐项汇报添加、重复和失败，暂时失败的项目保留以便重试。
- 合集批量成员更新改为单次事务。成员选择器按需分页搜索，离开详情返回时保留已有影片和滚动位置，并显示保存反馈。
- 减少未显示占位时的持续动画及选片过程中的重复点击。网格随系统文字放大留出更多文字空间。
- 没有改动数据库备份结构、影片和观影记录的语义、网络依赖、Android 包名或签名策略。

验证结果和限制见 OPTIMIZATION_ROUND_029.md 末尾的交付记录。

# 片刻·焕新版 0.2.30

## 改进：撤销提示条加倒计时、跟手拖动、弹簧退场

### 倒计时进度条

参考 Telegram 的撤销提示，胶囊底部加一条细进度条，随剩余时间从左向右收缩。

- 高度 2.5dp，颜色用主题强调色
- 与提示条本体共用一个时间源：进度条走到头就是关闭时刻，
  不会出现「条走完了但还没关」的错位
- 拖动时暂停，松手后从当前位置继续

### 跟手拖动 + 弹簧退场

原来下滑关闭是等手势结束才动，观感是「突然消失」。

改成真正跟手：

- 按住往下拖，提示条实时跟随（向下跟手，向上有阻尼）
- 拖过 56dp 阈值后文字变淡，提示「松手就关」
- 松手未过阈值 → 弹簧回弹到原位，倒计时继续
- 松手过阈值或甩得够快 → 弹簧退场，把拖动速度带进仿真，
  看起来是「被甩走」而不是「凭空消失」

### 修复：下滑关闭时的闪屏

根因是 overlay entry 的移除时机。

原实现用 `Future.delayed(Motion.panel)`（固定 150ms）猜测退场时长，
然后移除 entry。但弹簧退场的实际时长取决于初速度，往往短于或长于 150ms，
两者不同步就会硬切一下——这就是「手动下滑取消时闪屏」。

修复：改为监听弹簧模拟真正结束（`whenCompleteOrCancel`）后再移除 entry。
另外退场从当前值出发而非固定从 1 开始，拖动过程中触发关闭时不会跳变。

## 新增测试

`test/ui/undo_banner_test.dart` 扩到 6 项：

1. 倒计时进度条随时间收缩
2. 拖动时提示条跟手位移
3. 拖过阈值松手关闭并提交删除
4. 弹簧退场结束后才移除，不会硬切
5. 拖动时倒计时暂停，松手回弹后继续
6. 视觉参数符合项目规范

顺带修了 `_handleUndo` 的一个隐患：原先先置 `_settled = true` 再调
`_settle()`，而 `_settle` 内部也有 `_settled` 判断，导致它直接返回、
entry 永远不被移除。现在只在 `_settle` 内部置位。

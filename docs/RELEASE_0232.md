# 片刻·焕新版 0.2.32

## 修复：底部四页切换不流畅

排查后发现三个问题叠加。先确认了一件事：**这段转场代码自 0.2.28 起没有改动过**
（与改闪屏前的版本逐行比对一致），所以是原本就不够好，不是这轮改坏的。

### 问题一：时长偏慢

`duration: Motion.slow`（320ms）。连续点四个页签时，动画追不上手，
第二次点击时上一次转场还没走完，观感就是「粘滞、不跟手」。

改为 `Motion.normal`（220ms），与 Material 底部导航的通行节奏一致。

### 问题二：新页从「灰暗」变亮，不是「滑进来」

原实现：

```dart
final opacity = active ? 0.35 + 0.65 * progress : 1.0;
```

新页起步透明度只有 0.35，头几帧明显比旧页暗，看着像「先变灰再变亮」。
这是上一次为修「切页闪一下」时抬高的起点——当时确实解决了透底问题，
但把观感弄糙了。

改为 `FadeTransition` 起点 0.62：立刻有实体感，只做很轻的明暗收尾。

### 问题三：手写 Opacity 每帧触发离屏合成

原实现在 `AnimatedBuilder.builder` 里每帧算 opacity 数值，再包一层
`Opacity`。`Opacity` 会触发 `saveLayer`（离屏合成），四个分支同时在场时
开销翻倍；而且 `builder` 每帧参与，子树有被重建的风险。

改为 `FadeTransition` + `SlideTransition`：

- 两者内部走 `RenderAnimatedOpacity` / `RenderFractionalTranslation`，
  动画对象复用，子树预先构造好传进去，不参与重建
- `RepaintBoundary` 放在最内层，切页时只有位移与透明度在变，
  页面内容本身不重绘
- 缓动曲线提到 `CurvedAnimation` 字段里，不再每帧 transform

### 保留的正确设计

旧页**只做位移、不淡出**。它退到背景里，如果淡出会露出 `Stack` 底部（空），
那正是之前「切页闪一下」的来源。这一点保持不动。

新页位移量从 0.08 降到 0.055，配合更短的时长，读起来更利落。

## 新增测试

`test/ui/branch_transition_test.dart` 4 项：

- 切页时长不慢于 260ms（防止有人改回 `Motion.slow`）
- 新页淡入起点在合理区间
- 切换时新旧两页同时在树里，旧页移除后新页仍在
- 开了「移除动画」时不套转场包装

另外更新了 `pages_test.dart` 里一处断言：它原先检查
`DrawHubPage` 外面包着 `Opacity`，现在改为检查 `FadeTransition` 的
opacity 处于 (0,1) 之间——测试意图不变，只是跟随实现。
